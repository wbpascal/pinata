- **Resolve a vtable slot** (helper used in part 1, kept in no repo file): vtable VA from
  `pdb.py Files/Server/NA2016/Zone00/Zone.pdb publics '_7<Class>@@6B@'` (ShinePlayer 006ea61c, ShineMob 006e5594,
  CharClass 006ae434); then in Python `from rtti import PE; pe=PE('Files/Server/2016/w00_Zone00/5ZoneServer2.exe');
  struct.unpack_from('<I', pe.b, pe.off(vt+slot))` and look the address up in the zone-pdb export. Many slots hit
  identical-code-folded bodies with unrelated names (e.g. `CGambleObject::GDTSO_GetGameStatus` = "return 0").

- Effect vftable: +0xc `equipTick`, +0x10 `fallback`, +0x14 `_execute(arg, target)`, +0x18 `_typeValidationCheck`.
