## Working notes

- **Read code** with `python3 -I tools/protocol-re/clean.py re-data/exports/zone-pdb - <addr…>` (PDB names); pipe
  through `grep -v -e funcallanalizer -e PerformanceRecorder -e __security_cookie` to drop profiler noise.
- **Handler signature** `ac_X(this, u16 handle, ShinePlayer *gm, int argnum, char args[12][33])`: `argnum` counts the
  word (argnum 2 = one argument), `args[0]` = first argument. Numbers via `atoi` / `ac_Scanf` (0 when missing).
- **Reply** = `ac_wall(gm, text)` = `so_ply_Notice` vt 0x784 → 0x2011 NC_ACT_NOTICE_CMD (§1.5). Map-wide notice =
  `so_AllInMap(AxialListWall(text))`. Map-wide packet = `AxialListPacketBroadcast(&gpp, len)` + `so_AllInMap`.
  Packet to self = `gm.vt[0x2fc]()` (socket) `.vt[0xc](gm, &gpp)`. WM socket = `sock2wldman`.
- **vt slot → name**: `rtti.py` vtables + PDB names. Scratch script (recreate if missing): build
  `pdbnames.tsv` = `grep '^//==== FUNC' re-data/exports/zone-pdb/decomp.c | awk '{print $3"\t"$4}'`, then index
  `rtti.vtables('Files/Server/2016/w00_Zone00/5ZoneServer2.exe')['ShineObjectClass::ShinePlayer'][slot/4]`
