The client reads it in the character-select scene as {u16 code, u16 value} (code 0xDB0 → keeps the value, `FUN_00475fb0`). Give it a layout and a meaning, and a name only if a string supports one.
- C01 found no client handler for `0x5802`, `0x7038`, `0x703a`, `0xa415` although the WM sends them to a client: document them as ignored by the 2016 client, not as missing.

## How to work

**One part per session.** Context is re-read on every turn, so a long session costs far more than several short ones.
Parts 1–5 are in the **Parts** table (column *Part* of the scope table); part 6 is the sweep, part 7 the review. At the start, read `docs/plan/status/W04.md` (its **State** line and **Working notes**) and take the first part
not done (no status file: part 1). Do only that part, close it (step 6) and end the session, even if context is left.
