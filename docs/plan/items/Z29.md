# Z29: Zone: party experience tables (`PartyBonusByMember.shn` / `PartyBonusLimit.shn` loaders of `HitMeList::hml_Load` and their readers) (added by Z28)

**Phase:** 2 · **Depends on:** Z03, Z28 · **Output:** `docs/pseudocode/zone/Z29-exp-tables.md`

## Goal

Z03 §8.2 documents the experience split but says "which loader fills which table was not traced". Z28 §3.8 documents the level-handicap table (`lh4ed_Load`, `PartyBonusByLvDiff.shn`). The party bonus and the per-level group experience cap are still undocumented. Document them so a rebuild loads the original files unchanged and gives the same party experience.

- Read Z03 §8.2 (`el_ExpDistribute` FUN_004828b0, `ExperienceDistribute::lid_Call` FUN_00483360, `ed_GiveExperience` FUN_00481890) and Z28 §3.8 (`lh4ed`). Do not redo those.
- PDB names (`clean.py re-data/exports/zone-pdb - <addr> …`): `HitMeList::hml_Load` FUN_004824d0 (zs_start_yellow, Z10 §7.1), `PartyExperienceBonusDouble::pebd_Load` FUN_00481bf0 (PartyBonusByMember.shn: `PB_PartyMember` u8 → `pebd_Bonus[]` = ratio / 1000, `pebd_MaxNum` check with ShineExit "Buffer max num", "Data error" asserts), its static initialiser `dynamic_initializer_for_'pebd'` FUN_006960f0 (built-in defaults; where `pebd_MaxNum` is set), `MaxExpGainAtGroup::megag_Load` FUN_00481980 (PartyBonusLimit.shn: `PSE_ChrLv` u8 → `megag_ExpLimit[151]`, unchecked index, "Data error" for a level 1…150 without a row) and its reader `GroupExpDistribute::NearFriendInformationSummary::nfis_ExpLimitCut` FUN_00482560 (who calls it, what the cut amount does).

**One part per session.** Context is re-read on every turn, so a long session costs far more than several short ones.
This item has no scope table: in the first session, split the work into parts of similar size (about 2500 decompiled lines each, plus a sweep part and a review part) and write the list into the status file. At the start, read `docs/plan/status/Z29.md` (its **State** line and **Working notes**) and take the first part
not done (no status file: part 1). Do only that part, close it (step 6) and end the session, even if context is left.

1. `AGENTS.md` is already in your context (do not re-read it); follow its **Context budget** section. Part 1 only: read

   docs/protocol/packets-<bin>.md` for all of them). For docs over ~15 KB and every `§` reference above, run
   `python3 -I tools/protocol-re/sect.py <file>` for the outline, then `sect.py <file> <§|regex>` for what you need. This
