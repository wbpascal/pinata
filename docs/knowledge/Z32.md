## Game types and data

- Gamble types (`go_Get_GambleType`): 1 `GBT_DICETAISAI`, 2 `GBT_SLOTMACHINE`. Table `GameType` keys: 23 gamble-house TaiSai,
  26 slot machine. 2016: TaiSai house cut `GBTaxRate[23].GB_TaxRate` = 10 ‰; slot tax 0 ‰, jackpot saving `GB_JP_BET` 100 ‰.
- TaiSai win table and bet limits: §1.6. TaiSai payout per gamer = Σ won dividends − cut − Σ lost stakes (§3.10, worked example §3.12).
- Slot machine payout recipe, RTP 0.822 with the 2016 tables: §4.6.
- Ticks of the gamble objects are 0.1 s.

## Coin reservations

- Coin changes are reserved with lock list `L.vt[0x70]` = `icl_StoreGBCoin(lock, u64 amount, sign, exchanged flag)` FUN_00489d90
  (releaser `CoinChange`, applied by `icr_Apply` FUN_00489be0 → 0xBC04).
- `InvenCellReleaser_CoinChange::icr_Reserv` FUN_00489d20 adds the pending coin change to `ReservedQuantity.cen` (money), not
  `gbcoin` (Z32-B27, §5.5): money checks that add `icl_ReservedQuantity` (FUN_0048b5d0) see pending coins as pending money.
