# Z20 knowledge: skill data boxes (facts other items need)

Full detail: `docs/pseudocode/zone/Z20-skill-data.md` (§ numbers below). Names are official (pdb2016).

## Globals and lookups

| What | Where | Use |
|---|---|---|
| `skilldatabox` (DAT_13286828, Z03's `g_SkillData`) | `SkillDataBox`, 0x4e0 (§1.2) | active skills; `sdb_ValidArray` = `SkillDataIndex[sdb_MaxValid]` sorted by ID |

## Load and reload

- Files (§2.1): ActiveSkill, ActiveSkillInfoServer (same row count, same IDs per row, else exit), ActiveSkillGroup,
  ToggleSkill, AreaSkill; PassiveSkill, PSkillSetAbstate. Column → member maps: §2.2 (active), §6.2 (passive).
  All rows are used as they are (the `BinaryDataBox<T>` buffer is the row storage).
- `&reloaddata ActiveSkill` (Z11 §8.6) re-runs only `sdb_Load`: it deletes and reallocates `sdb_ValidArray`, so every
  stored `SkillDataIndex*` dangles. Holders (§7): the item use-effect table `useditemeffect.uie_FuncStruct[].useskill`
  (never rebuilt), `ui_ride` / `ui_Pet` skills, `NPCAction::SkillAction::skillIndex_`, magic fields
  (`smfm_skillindex`), pending skill blasts, the produce cast. Skill lists, mob skill tables and abstates keep **IDs**.
  `skillnametree` is never cleared.
- Duplicate active IDs are not detected (2016: 9034 twice, Z20-B4); duplicate passive IDs are fatal.

## Per-player lists

- `CharacterPassiveList` (§6.5): a 1000-bit `cpl_Passive` (IDs ≥ 1000 refused) + `cpl_SetAbstateList`;
  `cpl_RecalcParam` FUN_00445940 **assigns** (not sums) the passive Plus / Rate members, highest learned ID wins;
  HP-conditional bonuses go through `ChangeByConditionParam::cbcp_SetCondition` FUN_004c8f10.
- Passive set-abstate triggers: `ShinePlayer` vt 0xbf8 `so_ply_PassiveSetAbstate(c, target, flag, x)` FUN_005798e0;
  c 0 / 3 from `smo_SwingDamage` and `sds_TemplateStore`, c 1 from `sbe_BlastObject` / `sbe_BlastLocate`, c 2 from
  `sp_NC_MAP_LOGINCOMPLETE_CMD` (§6.5).
- `CharaterSkillList::csl_Learn` FUN_0055b810 (via vt 0x624 `so_LearnSkill`): the new step inherits the previous
  step's cooldown end; list sorted by skill ID (§5.2). The rest of `CharaterSkillList` is Z23.
