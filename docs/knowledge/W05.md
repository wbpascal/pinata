## 2. Facts for other items

- **`gServer` member table** (offsets of every `WorldManagerServer` member the WM process uses): W05 header table.
  PDB layout "definition 1" matches the 2016 offsets.
- **`CWMClientSession` layout:** use PDB **definition 2** (0x1f7b8 bytes). The `wm-pdb` export types the class with
  definition 1, whose members are shifted 4–8 bytes from +0x6b8 on: member names printed by `clean.py … wm-pdb` for
  client-session fields beyond +0x6b8 are wrong; trust the offsets (e.g. +0x1ed20 `m_SessionMode`, +0x1ed24
  `m_dActiveTime`, +0x1ed00 `m_bFirstJoinSend_WMTime_ToClient`).
- **Session pools** (`CWMBaseSessionManager`, vftables, `SESSION_STATUS` 0–4 + CharDB load states 5…0x18): W05 §4.1.
- **Dispatch tables:** `PROTOCOLFUNCTIONTEMPLETE<T>` = `pft_funcpnt[1024 commands]` → 64-department rows, allocated per
  command; one folded `pft_Store` FUN_00427260; duplicate registration → `ShineExit`. 486 WM registrations. W05 §6.1.
- **Handler return value:** 0 closes the link (all parsers), W05 §5.1. Handler `len` = 2 + payload length (frame
  length byte, `CPacket::GetDataSize` FUN_004678c0).
- **Data tables:** every SHN the WM loads, order, destination, fatal or not, user: W05 §3.2; `ServerParam` keys
  (`GetValue` FUN_00459f10): §3.3. The client-SHN checksum list (`CShnDataFileCheckSum`, 49 names) is built but never
  read in the WM (§3.4).
- **Timed services** and their periods (`ProcessContents` FUN_00406760): W05 §2.1. 0x0849 server time to clients once a
  minute + on first map login: §2.2. Quest reset times 0x441C / 0x441D: §2.3.
- **Close triggers** of a client session (socket drop, heartbeat, login timeout, kicks, duplicate login, DB errors) and
  what each tells AccountDB / AccountLogDB / CharDB / zones: W05 §4.5.
- **Windows service:** installed as a manual-start own-process service on the first run without arguments; stop and
  shutdown both run `OnStop_Service` (§6.3). Crash dumps: `<exe>_<time>.mdmp` + `…CallStack.txt` (§6.3).
- **Shared library** (IOCP sockets, acceptor, buffers, `CCsl` config scripts, `CGdp`): not documented yet, follow-up
  item S02 (added by W05).
