# Z25 knowledge: skill special effects

Facts other items need, from `docs/pseudocode/zone/Z25-skill-specials.md` (cite its § for details). Names are
*(pdb2016)* (NA2016 `Zone.pdb`, same build) unless marked.

## 1. Structures and tables

- `SkillDataIndex` special members: `EnumStruct { u8 exist; int value }` at `0x078 + 8·k`, `sdi_HEALAMOUNT` (0x78)
  … `sdi_RANDOMTARGETSPOT` (0x260). Offsets of the ones a blast reads: Z25 §1.1; who reads each member: Z25 §1.1.1.
- Never read in 2016 (set from the SHN only): `sdi_DISPEL`, `sdi_TELEPORT`, `sdi_WHOLEHEALAMOUNT`, `sdi_SILVERWING`,
  `sdi_AREATYPE`, `sdi_HEALFRIENDRATE`. Teleport skills are recognised by `EffectType` SE_TELEPORT.
- Raw offsets used by other docs, with their names: Z09 §7.4 `sk.+0x130` = `sdi_FLYDURINGCAST`, `sk.+0x260` =
  `sdi_RANDOMTARGETSPOT`; Z09 §6.2 `+200 / +0xcc / +0xd4` = `sdi_WHOLEAGGRORATE.exist / .value`,
  `sdi_WHOLEAGGRORANGE.value`; Z09 §7.4 `+0x220 / +0x224` = `sdi_RANDOMTARGET.exist / .value`.
- `MultiHitType.shn` → `_MultiHitTable` (`mht_Load` FUN_004c0ff0, Z25 §6.4.1): per ID up to 10 `OneHit`
  `{ oh_HitTimeRate, oh_AbState, oh_AbStrength, oh_AbStateRate, oh_DamageRate, oh_AreaStep }`, in file order.
- `MultiHitArgument` `{ mha_HitStep, mha_DamageRate, mha_AraeStep, mha_AbState[4] }`: `mha_HitStep = −1` = skill
  without `HitID` or a chain wave after the first (single-hit tail, abstates via `so_SkillEnchant`); `≥ 0` = MultiHit
  step k (applies `mha_AbState[0]` from the table). Filled by `sbec_Store` FUN_00438380 (Z25 §6.4). Answers Z22 §10.7
  "not traced".

## 2. Behaviour facts

- `sas_Find` FUN_00416c10: a `SubAbState` row with Strength 999 matches every strength (answers Z22 §13).
- `aeo_Set`: a non-zero keep time drops the `extra` argument (Z25 §1.4).
- SS_HOLDME puts abstates 392 / 393 on the **caster**, not the target (Z25 §2.7).
- vt 0x654 (card collection hook after a blast) is an empty `ret 4` FUN_00549070 in every class.
- `so_SkillEnchant` 5th argument (Z22 §10.7 "unused") = `canDamage`.
- vt 0xbf4 = `smo_LightningWaveSkill` FUN_005796a0 (chain blast, packet 0x245E). Corrects Z03 §5.4 "summon /
  self-target variant" and Z03 §5.6 "summon skills: vt 0xbf4".
- `smo_SkillResultPacket` FUN_0057a630 sends nothing (mage classes: `smo_BashStop`). Corrects Z23 §8.5 / Z03 §5.4
  "0x2452 with one missed entry".
- Mobs pay SP twice for a skill (vt 0xedc and vt 0xee0 are both `smo_SPCheck`; Z25-B19).
- Damage reflection: `smo_ReflectionDamage` FUN_0055dbc0, packet 0x245B, client FUN_004b6980 (Z25 §4).
- Dispel / cure masks → `AbState.shn` `DispelIndex` / `SubDispelIndex`: Z25 §5 (bodies in Z22 §7.5, Z23 §8).
