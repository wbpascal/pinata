# Z19 knowledge: the CSL config-script reader in all servers

Output: `docs/pseudocode/zone/Z19-config-script.md` (format spec §2, reference reader §4, other servers §5).
Pseudocode of the library: S02 §2–§3 (WM build).

## Facts for other items

- **One reader everywhere.** `CToken` (15 functions), `CCsl` (29) and `CGdp` (24) are identical at instruction level in
  all seven 2016 servers (Zone, WM, Login, Account, AccountLog, Character, GameLog); their constant tables (`pCslCmd`,
  `pCslParameter`, `pCslParameterSize`, `pCslRemarks`, default markers) are byte-equal (Z19 §5.1). Build-specific:
  Zone adds `CToken::GetTokenID` and lacks `CCsl::ViewResultMsg`; WM / Login have `ViewResultMsg`; the data servers
  have neither. Address table for Zone / Account / AccountLog / Character / GameLog: Z19 §5.2.
- **Format spec for a rebuild**: Z19 §2 (tokens, remarks, the ten commands, 18 column types and stored sizes, rows,
  include paths relative to the including file, errors, limits). Shipped files use only `#DEFINE` / `#ENDDEFINE` /
  `#INCLUDE` / `#END`, `<INTEGER>` / `<STRING>`, `;` remarks, CRLF.
- **Row kind = `#DEFINE` index** (`CSL_DATA_LIST.dwID`, file order across includes): `MY_SERVER` 0, `NATION_NAME` 1,
  `WORLD_NAME` 2, `SERVER_INFO` 3, `ODBC_INFO` 4 in every `*ServerInfo.txt` + `ServerInfo.txt`. This confirms D05 §7.4's
  *(inferred)* "kind is the `#DEFINE` order".
- **Current directory**: every server's start function `_chdir`s to its exe's directory before reading (Z19 §5.4), so
  all config paths are relative to the install directory.
- **Data-server `CServerInfo`** (Account = AccountLog = Character = GameLog): `GetServerIndex(id, world, zone)` has
  3 keys (the zone's has a 4th, `nServerIDFrom`); `GetODBCInfo(dbId, world)` exists only there (Z19 §5.3).
- **Character server**: three `CServerInfo` objects, `+0` (`DataServerInfo_Character.txt`), `+0x209890`
  (`DefaultCharacterData.txt`), `+0x209f4c` (`TutorialCharacterData.txt`); ctor FUN_0043eb40, read by
  `ReadServerInfo` FUN_00449410 from `GameData_Load` FUN_00401550 (Z19 §5.4).
- **Name corrections** (`tools/protocol-re/names/{character,gamelog}/Z19.json`, official names of identical code;
  they override D05's names in `clean.py` output): GameLog `Scriptor_ReadFile` FUN_0040e7c0 = `CCsl::ReadScript`,
  `Scriptor_Directive` FUN_0040cd60 = `CCsl::ProcRemark` (its 7-entry table is `pCslRemarks`: 3 null slots, then
  `#SEPRATOR`, `#REMARKLINE`, `#REMARKSTART`, `#REMARKEND`), `Scriptor_Report` FUN_0040cb40 = `CCsl::AddResultMsg`,
  `Scriptor_Summary` FUN_0040d5f0 = `CCsl::ReadScriptDone`, `ServerInfo_GetServer` / `ServerInfo_FindServer` /
  `ServerInfo_FindODBC` / `ServerInfo_LookupServer` FUN_0040feb0 / FUN_0040ff60 / FUN_00410030 / FUN_004100e0 =
  `CServerInfo::GetServerInfo(info, row)` / `GetServerIndex` / `GetODBCInfo` / `GetServerInfo(info, id, world, zone)`.
- **Bugs**: none new; the reader's bugs are S02-B11 … B22 and apply to every server (Z19 §6 has the per-build
  addresses).
