## Facts and corrections for other items

- **Z08 (done) corrections**, each documented in Z16: the KQ map instance is found by `MapName`, not `MapBase` (§1.2);
  0x580D's `local` flag is the last listed map, not "all maps local" (§2.1, Z16-B2); a declined recall 0x749C is answered
  with 0x1440, not 0x1441 (§6.3); an open NPC menu / storage gives 0x74AC / 0x74B4 the mode codes 0x1A41 / 0x1A59, not
  0x1A42 (§6.8, assembly); Z08-B12 (seed bound) is Z16-B17 (`seed ≤ 32` against 32-entry tables, §6.1).
- **W03 (done)**: the zone's 0x74E3 entry check is guild + money only (W03 §8.2 also lists level / members) (§6.7);
  0x74C9 FIGHTER_OUT carries the tournament type in its seed field (Z16-B10); the zone sends 0x7482 once per match
  (`gta_Result2WMS`): from the script's `endofgt`, or as a draw {nStatus 1, guilds 0} from the once-a-minute
  `wms_GuildTournamentCheck` when the instance's films have ended without one (§6.6).
- **Z03 / Z09 (done)**: vt slot 0xc70 is `so_MoverSystem_NoDamage` (player: rides a mover with an ability; mover: has
  mover data but no ability), not "GM-invincible". `ShineMover::so_mobile_IsEnemy` FUN_004309a0 is in Z16 §4.7, with its
  inverted `fm_MapInfo` test (Z16-B21).
- `RemoveWhen` *(pdb2016)*: REMOVE_NOW 0, REMOVE_LOGOUT 1, REMOVE_WARP 2, REMOVE_REVIVE 3. so_LinkTo: same zone → NOW (cmd
  0x4f → REVIVE), other zone → so_banning(p, 0) = NOW; WM kick-off so_banning(p, 1) = LOGOUT, which arms
  `sp_Schedule_Kickout` FUN_00558080 (10 s, then NOW). GT `PlayerUnRegister` and `sp_KQItemDrop` run only for NOW (and
  `sp_KQItemDrop` also for REVIVE) (Z16 §2.6, §4.4).
- 0x580C NC_KQ_START_CMD has no sender in the 2016 zone or WM; the client ignores it.
- `GTIView.shn` is loaded by the zone only for the SHN checksum list; nothing reads its rows.
- GT time base: the entry window is `nExploerTimeMin · 4800 / 10` ticks of 0.1 s, so 80 % of the minutes the WM sends
  (Z16-B19).
