# Z02 knowledge: zone movement, chat, sight, NPC menus (facts for other items)

Pseudocode: [`docs/pseudocode/zone/Z02-actions.md`](../pseudocode/zone/Z02-actions.md). Names:
`tools/protocol-re/names/zone/Z02.json`. Layouts: `docs/protocol/annotations/Z02.json` (67 packets).

## 1. Corrections and additions to Z01

- **`g_Now` (DAT_14d41a70) counts tenths of a second**, not milliseconds: `zs_mainthreadfunction` (FUN_005aca30) sets
  it to `elapsed_ms * 10 / 1000`. Every `g_Now + N * 10` in the code is "N seconds". Z01's "next save = now + 6000"
  is therefore 600 s (10 minutes).
- **Player modes** (`p+0xe9c`): 1 normal stand, 2 combat stand (client `Char::StandMode` COMBAT), 3 dead
  (client `Char::SetMode` calls `OnDead`), **4 resting in a tent** (0x2027 sets it, 0x202A clears it),
  **6 riding a mount** (0x2044 RIDE_FEEDING accepts mode 6 only; MOVERUN in mode 6 is ignored while the mount is
  hungry, +0x2a778). Mode 5 is treated like 4 by the tent check (another rest/house state, not identified).
  Extra masks seen: 0x06 {1,2}, 0x10 {4}, 0x40 {6}, 0x4E {1,2,3,6}, 0x56 {1,2,4,6}.
- **Handler signature:** `ClientSession_zbs_Parsing` (FUN_004fb9f0) calls `handler(ecx = player, pkt, len, arg)`;
  `arg` is used by the handlers as the player's own object handle (broadcast "handle" fields).
- **`player+0x7f32`** points at the payload of the player's own 0x1C06 NC_BRIEFINFO_LOGINCHARACTER_CMD (0xEB bytes
  in 2016; 2017 PDB struct is 0xEF): +0x52 polymorph, +0x54 emoticon {u8 id, u16 frame}, +0x25 shapedata (0x2b bytes),
  +0xc6 sAnimation[32] (2017 PDB: +0xca, so 4 bytes before it are missing in 2016). The packet object is at
  `player+0x7e34`; other objects keep theirs at mob +0x1ecc, drop item +0x167, door +0x1ea8, mini-house +0xc0a8.
- `player+0x168` / `+0x16a`: last move broadcast (cmd + 22 payload bytes), replayed to newcomers.

## 3. Shared mechanisms

- **Sight.** The client asks for unknown objects with 0x1C01 (`GameFrameWork::GetCharByHandle` →
  `NcBriefInfoCmd`), the server answers with the object's appear packet + last move. Full exchanges
  (`so_ExchageBriefInfo`, batched 0x1C07 / 0x1C09 …) run only at login complete, regen, teleport, hide-except-me
  off and scenario camera moves. Sight radius² `g_SightDistSq` = MapInfo.Sight² unless more than a threshold of
  objects are within 500 units (then a table shrinks it). Sub-layer visibility is a 6×6 table `g_SubLayerCanSee`.
- **NPC roles** (`World/NPC.txt` Role column → `NPCRole_*` classes) and `ServerMenuActor` yes/no dialogs (0x3C01 /
  0x3C02 / 0x3C0F) are generic: Z06 (shops, storage), Z08 (quests, instance gates) and scripts reuse them.
  `NPCRole_Merchant.nrm_ShopMenuOpen` builds the shop list packets 0x3C03/04/06 and 0x3C09/0A/0B.
- **`World/Field.txt` FieldList row** at `field+0xc`: CanTrade 0x9c, CanMiniHouse 0x9d, CanItem 0x9e, CanSkill 0x9f,
  Chat 0xa0, Shout 0xa1, CanBooth 0xa2, CanProduce 0xa3, CanRide 0xa4, CanStone 0xa5, CanParty 0xa6
  (packed offsets from the file's `#ColumnType` line; Chat/Shout/CanMiniHouse/CanItem/CanProduce checked in code).
- **Script hooks** used by actions: `field.CinemaComplex.cc_ScriptInterrupt(sim_NPCClick | sim_AreaEntry | sim_AreaLeave)`,
  Lua triggers for chat and jump (`LuaFuncTrigger_TriggerChat` / `TriggerJump`), `p.vt[0xa38](kind, a, b)`
  (kind 7 moved, 4 emotion), NPC AI-script events 0x20 (clicked) and 0x3c (menu answer). For Z09.
- **Spam filter** tables `SpamerPenaltyRule.shn` / `SpamerPenalty.shn`, message 0x0848 (W04 may meet the WM side).
