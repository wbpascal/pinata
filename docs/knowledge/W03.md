## Facts other items need

- **C01 open questions:** 0x742A (war score), 0x982E (academy member promoted to guild) and 0x985E (academy dismissal
  notice) are sent only to clients (online guild / academy members), never to zones or the DB; the 2016 client has no
  handler for any of them, so they are ignored. C01's handler for 0x985A (FUN_00404a00) is `TextData3::Get`; the real
  handler is `GuildAcademyMasterAppointTask::OnProcessNetMsg` FUN_006f28c0. The WM does send 0x980A, 0x982A, 0x982B and
  0x982D to clients; 0x980A only on errors, because the success answer of 0x9809 goes out under opcode 0x9808 (bug
  W03-B20). The 2016 client ignores all four.
- **W01 correction:** the 2016 character delete 0x1407 (FUN_00412fa0) sends CharDB **0x1413 NC_AVATAR_GUILD_DATA_REQ**
  {handle, charNo, slot}, not 0x1408; the WM sends 0x1408 only after the guild check of 0x1414 / 0x1416 (W03 §4.5).
  Guild masters get 0x140A {0x00C7}; unknown guild 0x00C9; member not found 0x00C3.
- **W01 start-up:** CharDB link states 5–0x18 load guilds, emblems, tokens, all member tables, the tournament, its
  entry list, academies, all academy tables, academy ranking and the rank balance before clients are served (§9.1).
- **Zones (Z-items):** the WM tells zones about guilds only through 0x7448/0x7449/0x744A/0x744B (make/delete/member
  join/leave), war start/end 0x7443/0x7444, token balance 0x74C1, academy 0x9876/0x9877/0x9879, buffs 0x987A/0x987B
  (every minute), grade changes 0x9886, tournament 0x74E3/0x7481/0x74F4. Guild rename / retype are **not** pushed to
  zones. Zones answer the guild-storage grade with 0x749E/0x9870 (WM reply header uninitialised on errors, W03-B17).
- **War:** only the requesting guild's entry holds the war; the WM never sends 0x7466 (it fabricates the 0x7467
  answer: start = now + 5 min, end = +65 min); the result is written with 0x7468 at the end; cooldown 120 min.
- **Tournament schedule:** the WM computes the schedule itself from GuildTournament.shn (FUN_00444cf0) and stores it
  with 0x7499; phases 9/10/0xB fall back to 0, which schedules the next tournament.
- **Character DB (D-items):** the WM requests guild deletion hourly with 0x745A once dDismissDate passed; emblem
  state changes use 0x750D (one path sends the wrong opcode 0x110D, W03-B11); academy level-up 0x9854 carries
  GuildAcademyLevelUp.shn Point / BuffTime; academy rank balance 0x9857 is repeated every minute until 0x9858.
- **Server parameters used:** "Guild_CannotLeaveTime" (hours; 0 blocks leave / kick, W03-B2), "GE_Member_60Lv",
  "GE_Member_100Lv", "GE_Change_Month", "GE_Delete_Term_Date" (days), "Academy_CannotJoinNotTime" (minutes).
- Success codes are packet-specific: guild 0x0C41, academy 0x1780 (0x1788 for 0x9812, 0x17F0 set master, 0x1890 level
  up, 0x18B0/0x18B8/0x18C8 academy balance/ranking/start), tournament 0x0D40 / 0x0D50 / 0x1C40 / 0x1B58 / 0x1B60 / 0x1B68,
  history 0x3180, rename 0x1A40, retype 0x1A58, emblem 0x3700.
