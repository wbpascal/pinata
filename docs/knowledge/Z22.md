## 1. Actors and elements

- Every state has an **element** (class chosen per ABSTATEINDEX in `AbnormalStateList::AbnormalStateList` FUN_0040f1e0)
  and an **actor** (chosen per `SubAbState.shn` Type through `actorcluster.ac_SubStateList[Type]`, stored in
  `abstateidentarray[index]` +0 by `aeo_Set` FUN_0040a340). `abstateidentarray[i]` = 12 bytes
  `{ actor*, AbStateStr* entry, u16 Type, u16 SubType }`.
- Actor vt slots: §1.2 of the output (27 slots, callers). Element vt slots: 0x00 IndexString, 0x04 Routine,
  0x08 SetMain, 0x0c is-party (no symbol), 0x14 GetActMilliSec (no caller), 0x18 PreAttach, 0x1c Attach,
  0x20 Detach, 0x24 This, 0x28 MaxRestCount.
- Only `AbnormalStateTickRoutine` (every `SAA_TICK` ms) and `AbnormalStateEachTickRoutine` (every object tick) call
  an actor's `sasa_Routine`. A routine returning 0 stops `asl_Routine`'s walk for the bearer (Z22-B1).
- Element `aeo_Flag` (+0x00): bit 0 `f_Cured` (`so_SkillCure`), 1 `f_Dispeled` (`so_Dispel`: BOMBDISPELALL and the
  DISPELRANDOM pick), 2 `f_SystemRemove` (`sp_RemoveField`). Flagged removals skip the bomb / detach-process /
  exp-up / drop-up detach effects; plain expiry, DISPELONE / DISPELALL and a steal do not.
- Removal is always deferred: writers set `aeo_Tick.terminate = now`; the state ends on the next routine walk.
- `aeo_Set`: `terminate = setTime + ticks(keep) × SET_ABSTATEKEEPTIMERATE / 1000`, keep 0 → row `KeepTime + 999 +
  extraKeep`; `aeo_RestCount` (+0x54) = element vt 0x28.
- Party mains (party / couple / guild-academy enchants) tick every 50 clock ticks and re-set the member states
  themselves; `so_SkillEnchant` skips BitSet / Inform for them.

## 2. Dispel masks and the skill → abstate path

- `smo_Dispel` FUN_0057d8e0 builds a mask `1 << DispelAttr` (`DA_GOOD 1 … DA_BOMB 10`): friend: cure 0x18, else
  DISPELDEBUFF 0x04 | DISEASE 0x08 | POISON 0x10 | CURSE 0x20 | BOMBDISPELALL 0x400; enemy: DETECT 0x200, else 0x02;
  DISPELDEEPER 0x100 when the caster's own StaDeeper is on the target. Then `so_SkillCure` (vt 0x5a4) and
  `so_Dispel` (vt 0x5a8).
- `so_Dispel` kills servants whose data row has `Debuff = Dead` (`so_MiscTable` +0x58 bit 0, Z09) when the mask has DA_GOOD.
- `so_SkillEnchant` FUN_00431ca0 (vt 0x5a0): toggle-off removal, StaImmortal / StaAdlFLoussierIMT immunity,
  resist roll, keep time = row KeepTime (item-action `SEIT_KEEPTIME_RATE_INCREASE`) + empower bonus + passive
  `PassiveBuffKeepTimeUPRate` share (skill group 99 BiffTimeIncrease), `EF_JUSTENCHANTBATTLEOBJECT`.
- `smo_old_skill_blast` FUN_00579b50 / FUN_0057be40 (vt 0xea4) is never called in 2016.
