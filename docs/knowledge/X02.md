## 2. Facts found on the way that no other file holds

- **Handler return values (Login, WM):** returning 0 closes the session or link the packet came in on. The census of
  all 45 Login and 462 WM handlers is `confidence.md` §3.5.1; the handlers where that 0 is another party's send
  result are X02-B11.
- **A PDB name on a small function can be an identical-code fold** (the linker merged equal bodies and the PDB keeps
  one name): `CQuest::Occure_LevelChange` on the empty "no-op" handler FUN_004c2450, `so_GetKQTeamType` on the type
  getter of vt 0x4d0, `ShineObject::so_Gamble_ChangeCoin` on the empty function `sp_HPStoneUse` stores. Read the body
  before trusting the name.
- **`NETPACKETZONEHEADER` is a member of the 2016 PDB structs** of 211 server-internal packets, not always at
  offset 0 (§3.2.1): take a layout from `docs/protocol/pdb2016-layouts.json` before shifting a 2017 struct by 6.
- **Character money** has one store, `tCharacter.nMoney`; the zone never saves it as a value, only through ITEMDB
  procedures (§3.5.4 E41). Safe to edit with the character logged out.
- **A party-release map is a `CanParty` 0 map** (one flag, `FieldMap::fm_Regist2WMS` @ FUN_00461cf0).
- **Coverage is address citation**: `coverage.py` sees only functions reachable by direct calls from packet handlers.
  1 158 class-named zone functions and 98 WM ones are outside it (`confidence.md` §4.4; items Z31, Z32, W06).
- **DB setups and table edits for tests**: `docs/plan/capture-scenarios.md` §8 (S1–S16, SQL with save / restore, not
  executed) and §9 (X1–X7); `docs/plan/status/X02-shnset.py` sets integer cells of a `.shn` table.
