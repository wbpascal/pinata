## Answers to Z08's open questions (Z08 knowledge §2)

- **Quest DB codes:** 0xB41 ok everywhere; 0x4403 / 0x4418 fail 0xB43; 0x4405 fail 0xB42 (also when no record existed:
  `p_Quest_Del` needs exactly one deleted row); 0x4409 fail 0xB46; 0x441A fail 0xBC2 (reward item insert), 0xBC3 (money),
  0xBC5 (title), 0xB43 (quest store). Give-up and read do not delete: they store status 20 (PQS_READ_ABLE) with zero data.
  0x441A rolls back money / exp / items on failure, but never the title (D04-B2); fame is not stored by 0x441A (log only).
- **WT licence:** 0x5C06 Error 0x9B9 ok else 0x9BA (procedure codes 1–3 not told apart). 0x5C08 0x9E1 ok, 0x9E2 lot
  calculation failed, 0x9E3 licence not on the weapon, 0x9E4 delete error, 0x9E5 clear-item delete error, 0x9E6 clear-item
  lot error; an unknown DB result also gives 0x9E1 (D04-B10).
- **Guild tournament join 0x74E5:** 0x1C40 ok, 0x1C46 already registered (−1421), 0x1C45 level / member requirement (−1422),
  0x1C44 not enough money (−1423), 0x1C47 (−1424, meaning unknown), 0x1C41 anything else. The DB does not take the
  character's money; the zone applies its locked money on 0x1C40.
- **Holy promise cen reward:** 0x943F 0x1C60 ok, 0x1C62 nothing to show (−2224: no reward row and not a master), 0x1C61
  error. 0x9443 0x1C68 ok (the DB has already added the cen to `tCharacter.nMoney`), 0x1C6A no remaining money (−2226),
  0x1C6B (−2225), 0x1C69 error.

## For W03 / W04 (WM side of the answers)

- Every guild answer uses 0x0C41 for success; part-split lists use PartMask bit 0 = first, bit 1 = last (emblem info sets
  PartMask = 2 on the last part without the first bit). Guild DB part sizes: 3 guilds (0x7457), 9 members (0x7455), 3
  academies (0x9802), 13 academy members (0x9810).
- 0x704E / 0x7050 (`IMPROVE_DB_SET_KEYMAP/GAMEOPTION_ACK`) carry an uninitialised `nCharNo` (D04-B13); 0x7057 / 0x7059 send
  no answer when the get procedure fails after init (D04-B14).
- 0x7453 (single guild) lacks `nWarEnemy`, `dNotifyDate`, `sNotifyCharID`, `GuildClient.nNo` (D04-B15); 0x7457 has them.
- 0x748C's last byte is uninitialised (D04-B19); 0x74F7 answers success 0x0D50 even on DB failure (D04-B20).
- Guild history `nAction` = `GUILD_HISTORY_MSG_TYPE` (pdb2017): 0 created, 1 join, 2 leave, 3 banished, 10–13 grade master /
  sub-master / elder / guard, 100–103 academy created / join / leave / banished.
- Prison: 0xD80/0xD81/0xD82/0xD87 (add), 0xDA0/0xDA1/0xDA2/0xDA7 (alter), get 0xDB0 / 0xDB2. Imprisoning sets the login
  map to `EldPri` (896, 1122), releasing to `Rou` (5963, 9793) — hard-coded in the procedures.
- 0x986B academy reward: the Character server itself sends **0x9882 NC_GUILD_ACADEMY_DB_REWARD_WANT_CMD** to the WM
  (`SendToWorldManager`) when the academy could not pay everything.

## For D05 (GameLog)

Packets sent here: 0x043E / 0x0440 quest, 0x0432 / 0x0433 skill, 0x0518–0x051F quest rewards (also used by 0x5815 with
questid 0), 0x0454 weapon title (0x1A bytes in 2016 vs 0x16 in the 2017 PDB), 0x0459 / 0x045A, 0x048C / 0x048D guild create /
delete, 0x04A3 guild grade, 0x04AB–0x04B0 tournament rewards, 0x04AE tournament result, 0x044F item create, 0x0755 academy
master, 0xC810 quest finished. All item / quest logs use the constant map name "Need" (D03-B11).
