## 1. Facts other items need

- **Time:** `g_Now` = `clockwatch.cw_CurrTick` DAT_14d41a70 in tenths of a second. `chargeditemcheck.ct_1MinuteFlow`
  DAT_00aa43e0 / `ct_1DayFlow` are true for exactly one main-loop tick; `BossFieldContent::g_ServentBuffBossTable.sbbt_NextTick`
  DAT_14d6fcb4 is true one tick per 5 s. Main loop and once-a-minute work: §1.
- **Client packets are handled inside the player tick** (`ShinePlayer::so_Routine`, at most 1000 per tick, §2.5).
- **Object kinds** (`so_ObjectType`, vt 0x4d0): NPC 4, mob 5, magic field 6, bandit 8, servant 10, mover 11, pet 12;
  axial flags 0 (folded). Pool kinds used for allocation: 5 mob, 7 door, 8 bandit, 9 effect object. `so_IsMob` (vt 0x89c) is 1 for mobs, servants and bandits in mob form. Handle pools and
  `sohu_HandleSplit` FUN_00633650 (players 8000–9499 = pool 2; mobs pool 5): §15.3.
- **Mob members and slots:** member table §5.2 (PDB names); AI slots §6 / §7 / §8 working tables; movement slots §9.1;
  drop object members §11.4. Mob mode byte (`vt 0x484`): 0 spawning, 2 alive, 3 dead.
- **Random rings:** `RandomRing(n)` = ring DAT_14d720d0 + n × 0x8008, values 0 … n−1 (n 1…100); `g_Rng` DAT_150ba418
  (`cWell512Random`, `well512_GetRandom` FUN_0063cab0).
- **Range queries:** `so_AllOfRange(obj, range, visitor, includeSelf)`; range 0 = the map's sight (99999999 with wide
  sight or a moving camera); the per-map-kind functions behind `fm_BroadFunc` (normal / mini-house / …): §28.1.
- **Scripts:** Lua 5.2, one `lua_State` per file; object events (`LuaAi`) and map events (`LuaField`) are byte offsets
  of the name strings (§14.3); all 248 Lua C functions and their owner items: §14.9. Pine map scripts (`World/PineScript.txt`
  books, `.ps` wins over `.lua`): language §20–§21, nodes §22–§26, films §27. A Pine node step returning 0 **ends the film**.
- **Drops:** `so_IsDropping` FUN_004b0a20 is the common drop helper; looter = `ShineMultiTypeHandle {kind 0 player / 1
  party / 2 raid / 3 none, id, charNo}`; loot rule 3 = dice game (0x303B / 0x303E / 0x303F, `BelongDice.shn`) §11.6.
- **Tools pitfalls** (any zone item): Ghidra marks `operator delete` FUN_0065677f no-return, so code after it is missing
  from the decompile (check objdump); Ghidra swaps numeric Lua arguments in some wrappers (`cEffectRegen_XY`, `cFollow`):
  check the push order in objdump; many vtable slots are folded bodies (`return 0` FUN_00570b00, `return true`
  FUN_005af8d0, no-op FUN_00509900 / FUN_00417480) that carry an unrelated PDB name.
