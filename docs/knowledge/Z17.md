# Z17 knowledge: item actions and costume weapon/shield charges

Facts other items need. Full pseudocode: `docs/pseudocode/zone/Z17-item-actions.md` (§ numbers below). Names *(pdb2016)*
from the NA2016 `Zone.pdb` unless marked.

## Item actions in one paragraph

An item action (`ItemAction.shn` row → `Action`, §1.2) = a set of conditions (`ItemActionCondition.shn`, 6 classes + range
condition, §1.3–§1.5) and effects (`ItemActionEffect.shn`, §1.6), with an optional cool time per **group**
(`CoolGroupActionID`). Sources: equipped items and socketed gems (`ActionEffectItem.shn`, keyed by item id, §1.7), set
items (`SetEffect`), abnormal states (`ActionEffectAbState.shn`, §3.3). Each player owns an `ItemActionObserveManager`
(vt 0x5d0 `so_GetItemActionObserves`) whose observers come from one zone-wide pool of 5000 (`ItemActionObserveBuffer`).
Hook points (§3.4) call `EventRun*` with an `ItemActionArgument { condition {type, subtype}, effect {type, subtype}, me,
subject, object }`; a matching action either returns a value (rate / plus kinds: `AttackType`, `SkillEffectIncrease`,
`SetItemEffect`) or runs an immediate effect (Recover, AbState, Dispel). A success with a cool time starts the group's
cool-down and sends `0x482C` to the client.

## Costume charges in one paragraph

Classes 26 (weapon skin) and 37 (shield skin) carry a charge counter in the item attribute; capacity = `ChargedEffect.shn`
`EffectEnum` 28 `EE_WEAPON_MAXENDURE` (a new item is full), kits = `EffectEnum` 27 `EE_ENDURE_KIT`. One charge of each worn skin is
spent per normal swing (first hit of the swing, hit or miss; `sp_Schedule_SwingDamage`, §4.2), at most one per player tick;
skills never spend (Z17-B14). `sp_Schedule_SwingStart` stops auto-attack when a worn skin is at 0. Client and DB are told
every 10th charge (`0x3037` / `0x3066`, `0x348F` / `0x34C8`), and again on `smo_BashStop` (both) and `so_Unmark` (DB only)
(§4.3); at 0 the skin breaks (`0x3038`, CharDB `0x3459`, GameLog `0x0612`). Refill: Z04 §12.2 / Z05 §8.7.
