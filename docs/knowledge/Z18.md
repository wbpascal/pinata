## Facts other items need

- **Client session modes** (`ClientSession::SessionMode` *(pdb2016)*): −1 INACTIVE, 0 BEFORE_MAP_LOGIN_REQ (set at
  accept), 1 BEFORE_MAP_LOGINCOMPLETE_CMD (at 0x1801), 2 AFTER_MAP_LOGINCOMPLETE_CMD (at 0x1803). Z18 §1.3.
- **Per-IP limit**: at most 9 client sessions of one IP may be between accept and 0x1803; the 10th closes all 10
  (`csm_AddClientSessionToIPGroup` FUN_0045c720). Z18 §1.3.
- **Double login on one zone**: `sp_KeepFromDoubleLogin` FUN_0043cc90 bans every other player object with the same
  user number (account); `sp_GhostBan` FUN_0043f3d0 logs out of sight every player of the map with the same name.
- **ClientSession members** *(pdb2016)*: +0x100 `cs_sessionhandle`, +0x102 `cs_clienthandle` (player handle),
  +0x104 `cs_sessionMode`, +0x108 `cs_activeTime`, +0x10c `cs_bClosingSession`; peer IP at +0x34 (inside `m_SocketIOCP`).
- **Abstate element flag** (`AbstateElementInObject.aeo_Flag`, +0): bit 0 `f_Cured`, bit 1 `f_Dispeled`, bit 2
  `f_SystemRemove`; `aeo_Tick` (+0x1c) = `{start, terminate, Metronome nextaction}`.
- Vtable slots resolved for `ShinePlayer` (byte offsets): 0x2f0 `so_SetSocketSession`, 0x2f4 `so_EncSeedSet`,
  0x30c `so_FirstActionAfterSocketConnect`, 0x33c `so_Unmark`, 0x344 `so_GetCharRegistNumber`, 0x348
  `so_GetUserRegistNumber`, 0x484 `smo_GetMode`, 0x4d0 `so_ObjectType`, 0x52c `so_mobile_AbstateList`, 0x56c
  `so_CharName`, 0x5fc `so_banning`, 0x784 `so_ply_Notice`, 0x910 `so_LogoutLog`, 0x93c `so_ply_LoginIPSet`.
- **SubState → actor table** (Z22): `actorcluster.ac_SubStateList[120]`, built by `ActorCluster::ActorCluster`
  FUN_00405a10, read only by `aeo_Set`. Full mapping Z18 §3.1. `SubAbnormalStateActorDmgState` is never attached
  (Z18-B5); SubState 67 KNOCKBACK runs the Poison actor.
- **Abstate cap**: 28 simultaneous abstates per object (`AbstateListInObject`, Z18 §3.2).
- **MagicField actor**: only SubState 107, rows `SubStaEglack04` / `SubStaEglackMad04` (tick 1000 ms,
  `SAA_SETACTIVESKILL` 29408 / 29414), abstates 494 / 501.
- **`smo_SkillBlastOption`** FUN_0057c750: max over abstates of actor vt 0x1c; 0 `SB_NORMAL`, 2 `SB_SILENCE`
  (actors Silence and Silencetoone; the latter ends its state on the first query).
- **Element class vt 0xc** = "party-type enchant" (`AbnormalStatePartyEnchant`, `…CouplePartyEnchant`,
  `…GuildAcademyMasterEnchant`): such states are not re-sent after login and cannot be stolen.
- **Dispel masks** (`smo_Dispel` FUN_0057d8e0 → `so_Dispel` FUN_0042bf70): bit n = `DispelAttr` n; friendly CURE 0x18,
  friendly DISPEL from DISPELDEBUFF / DISEASE / POISON / CURSE / BOMBDISPELALL (0x4 / 0x8 / 0x10 / 0x20 / 0x400), enemy
  0x2 (GOOD) or 0x200 (HIDE, with DETECT) or 0x100 (DEEPER, own STA_DEEPER only). `f_Dispeled` is set only by
  BOMBDISPELALL and the DISPELRANDOM pick; `f_Cured` by `so_SkillCure`.
- **Trap blasts** 0x2442 / 0x2443 come only from `meb_Explosion` (Z09 §8.8) via `smo_SkillBash_Blast_Trap`; layouts in
  `docs/protocol/annotations/Z18.json`.

  `so_Disconnect`, 0x638 `so_AbnormalState_Set`, 0x648 `so_AbnormalState_Set_SS_SETABSTATEME`, 0x6cc `so_BodySize`,

- **Equip slot rules** (Z18 §4.2): `ItemServerEquipTypeInfo.shn` (34 rows, `ISET_Index` from ItemInfoServer) byte 1 =
  the item's slot, 2 = also covered; `equipman.eec_Column[ItemEquipEnum]` = byte offset (table in Z18 §4.2).

  partial:1), u16 itemID, u64 key, u16 attrOffset, u16 inven, u64 keys[]}` + the partial cell's attribute bytes.
