## 2. Facts for other items

- **Z13 (mini-house):** the house TaiSai state (house vt 0x1bc–0x2a8, offsets +0xc6e0…+0xd0f8, player vt 0x170–0x1b8) is documented
  in Z06 §3; Z13 can cite it. The house routine `so_Routine` FUN_00567400 runs the dice timer (§3.4).
- **Z11:** `&ts_DiceFix` / `&GB_DiceFix` store dice for the next roll only (house vt 0x1cc FUN_005117d0, flag +0xc755);
  `&ts_DiceProbability` / `&GB_DiceProbability` set one of the 216 outcome weights (FUN_00511830; null = reload DiceRate.shn).
- **Z07 (open question answered):** WM `0x10DD NC_CHAR_ZONE_COININFO_CMD` → player vt 0xb00 FUN_00615d10 sets coins (+0x2aa70) and
  exchanged coins (+0x2aa68) and sends `0x10DE NC_CHAR_CLIENT_COININFO_CMD {u64 coin, u64 remaining exchangeable}`.
- **Z07 / Z12 (titles):** trades update CharTitle counters at `+0x4f8` (type 6, money given) and `+0x508` (type 7, money received)
  with a 30 s / different-partner anti-farming rule (FUN_005cbcd0 / FUN_005cbd50); TaiSai wins feed FUN_005cc490.
- **Z09:** the drop-item dice game (`ShineDropItem::so_DiceItemPickInit` FUN_00531020, `0x303B/0x303E/0x303F`, BelongDice.shn) and
  party loot FUN_00644f60 are not part of Z06; Z09 has a step for them.
- **W04:** the WM sender of `0xBC09` (FUN_0043c2d0) is a W04 step.
- **Z17:** item actions and costume weapon/shield charges (pointed here by Z03) moved to the new item Z17.
- **D03:** zone→Character requests and their layouts: `0x343B` (trade), `0x3453–0x3455` (booth), `0xAC0C/0xAC10/0xAC17/0xAC23/0xAC25/
  0xAC2C` (mini-house dice), `0xBC0A/0xBC11/0xBC15/0xBC6C/0xBC78/0xBC7A/0xBCD3/0xBCD5` (gamble). Success codes the zone tests:
  dice roll 0x1CF0, income 0x1D00, item-id change 0x1D28, coin buy 0x2808, coin sell 0x2810, coin item 0x700, gamble roll 0x2680, slot 0x28D8/0x2900.
- **W01/W04:** zone→WM `0xBC1D NC_GAMBLE_WORLD_PREVMAPNAME_CMD {wmHandle, map[12], charNo}` and `0x402C {wmHandle, u64 coin,
  u64 exchanged, charNo}` are written by `ws_save2worldmanager`; WM→zone `0xBC01` (return map) and `0xBC09` (daily coin reset).
- **Z05:** slot-machine jackpots request a reward item with `0x344D NC_ITEMDB_CREATEITEMLIST_REQ` (key kind 0xB, table DAT_14d70e38 row 0x1a).
- **Z02:** `MapInfo` row `+0x9c` CanTrade, `+0xa2` CanBooth, `+0x9e` gamble/VIP card allowed; FieldList row `+0x3a == 7` = gamble house.
- **X01:** bugs Z06-B1 … Z06-B19 in §6 of the pseudocode.
