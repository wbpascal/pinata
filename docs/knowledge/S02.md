# S02 knowledge: shared server library (network, config scripts, packed files)

Facts other items need from `docs/pseudocode/shared/S02-library.md`. Login, WM and Zone link the same library source;
S02 reconstructs it from the WM build (`wm-pdb`) and maps the Login / Zone copies (§1.9, §2.7, §3.6).

## Network (§1)

- **Send buffers**: 16 containers × 512 pre-allocated `CIOBuffer`s of 0x2010 bytes (data 0x2000) at static init,
  ~67 MB per process; more come from the heap and are **never freed** (pool only grows). Spin lock falls back to
  `Sleep(1000)`.
- **IOCP workers**: Login / WM start `2 × CPU` workers, Zone `2 × CPU + 1` (result ignored); a failed `CreateThread` hangs the start (S02-B32); the completion key is unused, everything comes from the
  OVERLAPPED (`pIOCP_Process`, `pData` = session).
- **Acceptor**: one thread, `select` over up to 10 listen sockets (non-blocking, `SO_REUSEADDR`, `SO_SNDBUF` 32 KB),
  accepted sockets go to one ring shared by all ports; each entry carries the listen slot's `UserData` (peer server
  type), which picks the session pool in the main thread's connect step.
- **Outbound links** (`CSocket_IOCP::Connect`): blocking `connect` with no timeout on the caller's thread (S02-B5).
- **Send**: data is split into ≤ 0x2000-byte chunks and queued; one write in flight; queue unbounded (S02-B6); a
  partial write drops the rest of the queue without closing (S02-B7).
- **Receive**: one 0x2000-byte `CPacket` buffer per session. Frame = `[size u8 ≠ 0][op u16][data]` or
  `[0][size2 u16][op u16][data]`; size counts op + data. Longest frame 0x2000 bytes. `IsValidPacket` returns 0 (need
  more), 1 (frame ready), 2 (bad → session closed). Long frames with size2 0 / 1 are accepted (S02-B10).
- **`CPacket` vtable slots** (all three servers): 2 IsValidHeader, 3 IsValidPacket, 4 GetPacketSize, 5 GetDataSize,
  6 GetIDPtr, 7 GetDataPtr, 8 GetPacket, 9 TakeNextPacket, 10 RemoveAllUsedPacket, 11 Clear, 12 ID(op,len,data), 13 ID().
- **Zone difference**: no `CSendPacket`, no `Listen_Stop` (`~CIOCP` closes the port); a failed completion does not mark
  the session closed, so a reset connection lives until the heartbeat check (S02-B8).
- `CGTimer::GetTime` = `timeGetTime()` (ms); every library timestamp uses it.
- **Zone ring neighbour** (§4.4): `zipc_GetNextZoneNo(own)` = own + 1 if that slot of `ZoneIPContainer` (12 slots) has an
  address, else 0 (wrap); `zs_ServerConnect2Zone` connects to it with `ConnectSocket_BindIP`, so a lone zone 0 connects
  to itself (inferred); its "no next zone" checks are dead (S02-B33). Every Zone session class derives from
  `ZoneBaseSession` and gets the `IOCPProcessSession` callbacks; heartbeat limits 30 s / 180 s are constants.

## Config scripts (§2)

- `CToken` (tokenizer) + `CCsl` (script reader) read every `*ServerInfo.txt`, the shared `9Data/ServerInfo/ServerInfo.txt`
  and the Character server's `DefaultCharacterData.txt` / `TutorialCharacterData.txt`. Grammar: §2.4; byte-faithful
  reader: `tools/protocol-re/csl.py` (all shipped 2016 scripts parse with 0 errors).
- `#DEFINE name <TYPE> … #ENDDEFINE` defines a format; a data row starts with the format name; `dwID` of a row =
  index of its `#DEFINE` in the file (include order). Delimiters `", \t\r\n"`, remarks `;` and `/* … */`.
- **Rows store strings inline** (`<STRING>` 512 bytes, `<FILENAME>` 260); `SERVER_INFO` holds pointers into the row.
- `[…]` optional types are not optional (S02-B21); LF-only files lose the line after a remark-only line (S02-B16);
  a script must end with `#END` or a non-delimiter (S02-B14).
- `CCsl::ViewResultMsg` has no caller; servers print the messages through `CServerInfo::ViewErrorMsg` after a failed read.
- `CToken` is also the Zone quest-script tokenizer (`CQuestParserScript`, zone-only `CToken::GetTokenID` FUN_0063b2b0).

## Packed files (§3)

- **`CGdp` container mode is dead in 2016**: `m_bIsGDPOpen` is only ever written 0, no container open function is
  linked, the `GDPID` constant 0x1A504447 is in no 2016 binary and no file under `Files/` starts with `GDP\x1a`. Every
  `CGdp` call is a Win32 pass-through (`CreateFileA`, `ReadFile`, `SetFilePointer`, `GetFileSize`, `CloseHandle`).
  S02-B23 … B30 are in that dead code.

## Corrections to other items' docs (done items; not edited)

- `login-server.md` §3.1: `lastRecvTime` is set on **every read completion**, not per dispatched packet (S02 §1.6), so
  a peer trickling a partial frame keeps its heartbeat alive.
- W05 §1.4: the pump's `session.vtbl[…]` calls are slots of the session's `m_Packet` (`CPacket` table above).
- W05 §5.2 "strings are stored as pointers": true for `SERVER_INFO`, but the CSL row stores them inline.
