## 2. Facts

- Spam-block wire encoding (0x4021, 0x4022, 0x10CB): `BlockTime` ≠ 0 → both values are durations in seconds;
  `BlockTime` = 0 → `DelayTime` is the unix time the probation ends (0 = none) (Z31 §2.5).
- `ItemUseEffect` kinds that make an item usable for `UseItemByTable`: HPUP / SPUP / HPSPALLUP only when not full,
  POISON / DISEASE / CURSEREMOVE always, ABSTATE when `asl_CanEnchant`; NONE / DEBUFALLREMOVE / ACTIONITEM never
  (Z31 §2.2).

- Lock list (`InventoryCellLockList`, p+0xfaa8, Z31 §3.1-§3.3): 192 `LockedCell` entries of 0xa0; reservations
  without a cell use the pseudo cell `0x4400` (type 17). `vt 0x04(type, slot, ownIndex)` ignores the caller's own lock
  index, `vt 0x0c(type, slot)` does not. A full list only asserts (the caller still sends its DB request).
  `vt 0x64` sums open money / fame / soul-stone reservations into `ReservedQuantity {cen, fame, hpstone, spstone,
  guild_token, gbcoin}` (int each; coins go into `cen`, Z31-B3). Releaser slot 8 (busy) is true only for the plain
  `icl_OnlyLock` releaser and `GuildAcademyRewardStorageInfoZoneRng`.
- `ItemAttributeClass` has 51 slots in the zone; slot → method table in Z31 §3.5 (0x10 `iac_itemcreate(id, ShineReward*,
  iti)` for kingdom-quest reward items, 0x14 the GM `-o` option parser, 0x48-0x58 weapon licence slots, 0x7c / 0x80
  amulet upgrade options).
- Box sizes: equipment 30 cells, inventory 192, account storage 576 (usable 72 / 108 / 144 by `cec_MoreStorage`),
  guild storage 36, academy reward storage 72, reward storage 24 (Z31 §3.4).
- Dead in 2016: `CellStack` / `LinearStep` path tracer (no driver), `CharacterInventory::ci_FillBufferItem`
  (only from player vt 0x520 `so_fullbufferitem`, never called) (Z31 §3.4, §3.8).
- `ItemShop.shn` (`ItemMall`, Z31 §3.6): goods number → up to 10 `{item, lot}`; read by the premium withdrawal only.
- Every client command without a `pft_Store` runs `sp_DummyFunction` (assert + disconnect 0x0686) (Z31 §4.1).

  AccountStorage_opened, AStorageAnywhere_opened, LinkReserv_link, InAdminImmortal; byte 1 (p+0x5cb9) TryLinkUntilSuccess,
