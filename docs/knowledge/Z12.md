## 1. Stat matrix (`Parameter::Container`, `p+0xfc0`, size 0xdb0)

- Layer k at `P + k·0xcc` (cluster of 51 i32): 0 PureCharParam, 1/2 Item.Plus/Rate, 3/4 ItemPowerRate, 5/6 Upgrade,
  7/8 WeaponTitle, 9/10 PassiveSkill, 11/12 AbnormalState, 13/14 LastTune, 15 Total. Helper: `(off − 0xfc0) // 0xcc`
  = layer, `% 0xcc / 4` = member (table in Z12 §1.1; 35 MaxHP, 36 MaxHP_2, 37 MaxSP, 49 MaxLP, 50 LPRecover).
- `Total` only gets members 0–31; MaxHP / MaxSP / MaxLP / AttSpeed / resistances are read from the layers
  (`sp_MaxHP` FUN_0054a670, `sp_MaxSP` FUN_0055a8b0, `so_ply_Sen_MaxLP` FUN_005611e0).
- Rebuild: `so_allparametercalculate` (vt 0x57c) FUN_0054f190; refresh / client packets: `so_mobile_NotifyParameterChange`
  (vt 0x34) FUN_00503c10 → 0x1035 / 0x10DF (Z12 §4).
- `ItemPowerRate.Plus`, `Upgrade.Rate`, `WeaponTitle.Plus`, `LastTune.Plus` are never written (identity values).
- `CharClass` (`p+0xfbc`) vftable slots: 8 MaxHP, 9 MaxSP, 10 MaxLP, 11 LPRecover, 12 LPTick, 15 cc_AttackRhythm (Z12 §3.1).

## 2. Login blobs and options

- Every WM → zone character blob, its PROTO struct, the method that parses it and the members it fills: Z12 §6.1 table.
  0x1026–0x1028 / 0x102A–0x102D have **no zone handler** (dropped); 0x103C is never sent by the zone.
- `defskill` (DefSkillData DAT_0af0d288) is never filled: `csl_CheckDefSkill` is dead.
- Single options (0x10D3 / 0x402A): `sp_MiscFlag.IsAutoPickUp` (p+0x5cb9 bit 3) + brief `IsAutoPick`,
  `sp_MysteryVaultUI` (p+0x2aa44, sent as 0x10D4 at login complete; client 0x4025 changes it), `sp_Spammer_ChatBan`
  (p+0x2aa54, read by chat / shout / roar via `sp_IsSpameChatBan` FUN_00560a30). The zone always sends
  `resttime = 0`, `bFirstJoin = 0` in 0x402A, so rest exp is computed only at character login.
- Roll-back position (`sp_punMarkEvent`, p+0x5e08, `RollBackPosCallBackEvent`): set by 0x10B8 or the same-zone observer
  entry; overrides the **next `so_LinkTo` target** and the saved location (`so_SaveLocation` FUN_004542f0); run by the
  observer-out paths. Never cleared at logout / object free: stale in pooled player objects (Z12-B14). The event's record is
  not zeroed: name tails, `index`, `direct`, `Party` are heap garbage (Z12-B16).
