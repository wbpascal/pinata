## Facts

- World status values 0, 2, 4, 5, 6 … 10 and who sets them: L01 §3 table. Load bands from `NumOfUser * pct / 100`
  against `m_LoginUserRatable[world]` (defaults 3, 5, 8, 10, 30, 95 %; `nWMSUS_1` unused).
- Login pumps every buffered frame of a session per pass (5 ms sleep per pass); the WM only one (W05 §1.4).
- Client handles: slot + k × pool size, advanced on every release (L01 §2.3); Login uses no 0xFFFF handle value.
- `m_ppWSMappingTable` / `m_pWMClientValidationTable` / `m_LoginUserRatable` are indexed by world number
  (bugs L01-B1, L01-B2).
- Login has no client close callback: closing a client sends nothing to AccountDB / AccountLogDB / WM.
