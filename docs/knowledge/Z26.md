# Z26 knowledge: silver-wing teleport item

Facts other items need. Full pseudocode: `docs/pseudocode/zone/Z26-silver-wing.md` (§ numbers below).

## Data

- Item 2504 `SilverWings` (`itemdatabox.idb_specialid.sii_silverwing`, DAT_14d5048c, set by `idb_Load` FUN_00649780),
  class 13 bind item, never consumed. Actor `UseEffect::UseItemSilverWing` (`ui_silverwing`, registered for
  `ItemUseFunction` "UseSilverWings"). §1.1.
- Saved location = `ShineItemAttr_BindItem` *(pdb2016)*, only entry 0 used. Item cell offsets: +0x0a `portalnum`
  (0 nothing saved, 1 saved), +0x0b u16 `mapid` (`MapInfo` index, 0xFFFF if the field name is not in `MapInfo`), +0x0d u32 x,
  +0x11 u32 y. Character DB storage: option rows 1100 portalnum, 1110+10n map / +1 x / +2 y (D03 §1.3). Written through DB 0x3449 `NC_ITEMDB_ITEMCHANGE_REQ` (`sp_AttrChange2DB` FUN_005979b0); takes effect at the
  0x344A answer (Z05 §5.4). §1.2, §4.1.
- Pseudo-skill `ActiveSkill` 0x7210 `UseSilverWings`: CastTime 0, DlyTime 3 600 000 (stored, not used), SpecialIndexA
  = 19 `SS_SILVERWING` (the only row; `sdi_SILVERWING` is set but never read in the 2016 zone). §1.1.
- Cooldown = `cec_SilverWingCoolTime_Minute` · 60 000 ms (vt 0x3d8 FUN_005596b0); template 60, lowered only by charged
  effect EE 0, which no 2016 `ChargedEffect` row has: always 60 min with 2016 data. §1.1, Z24 §6.7.

## Flow

- 0x3015 → `uib_CanUseItem` FUN_00598000 (only `IsLink_OutMap`; 0x70F + notice "RecallDisableField") → `uib_DirectUse`
  FUN_0059c260 → `sp_SilverWingMenu` FUN_0059c090: server menu 0x3C01 (entries Fly (only if `portalnum` ≠ 0) / Save / Cancel,
  argument `SilverWingSet { inven = 0x2400 | slot }`), no 0x3016 until a menu callback runs. §2, §3.
- Save: `sp_silverwing_Setloc` FUN_0059bc80 (field `LinkIn` must be ≠ 0). Fly: `sp_SilverWing_PortalCast` FUN_00597b30
  (cooldown check `csl_CoolTimeCheck`, 0x70D; fills `smo_SkillCast` like an item cast). Cast end: `so_Routine` FUN_0056a080
  item branch starts the 60-min cooldown by item ID, `smo_ply_ItemUse` FUN_0053fd10 → `uib_AfterCast` FUN_0053ff70 →
  `sp_SilverWing_PortalBlast` FUN_00597cf0 → `so_LinkTo(link, 6, 9, 10)` to `MapInfo[mapid]` at (x, y). §4, §5.

- No 0x3029 item-use broadcast: `World/ItemUseFunction.txt` row `SilverWings` has BroadCast 0. §5.2.
- Second entry: 0x304E `sp_NC_ITEM_USE_ACTIVESKILL_REQ` FUN_00540b90 calls any item actor's `uib_AfterCast` directly (no
  `uib_CanUseItem`, no class check). For the silver wing: immediate blast + link without the LinkOut test (Z26-B7). Items
  documenting other actors should check what their `uib_AfterCast` does when reached this way. §5.5.

## Server-menu facts (Z02 does not record them)

- Official names *(pdb2016)*: FUN_0050f660 = `ServerMenuActor::sma_Clear` (Z02 calls it "sma_Reset"), FUN_0050fc00 =
  `sma_Reset` (Z02 "sma_Reset_new"), FUN_0050fd40 = `sma_Reply`, FUN_0050ec90 = `sma_IsReady` (`sma_Subst` == 0).
- `sma_Reset` runs the reset callback and sends 0x3C0F only when entries are registered; the reset callback is set only by
  `sp_ServerMenu_SetReserFunction` FUN_00549b30 → `sma_SetResetFuction` FUN_0050f800, used only by `ItemMenu_Open`
  FUN_0048ced0 (Z04 §1.5). Unregistered reply slots (index < 10) run an empty default (FUN_00509900). §4.4.
- `sp_EndOfTrade` resets the menu only when `sp_NPCProcess.npc` ≠ null: NPC-less menus (silver wing) survive 0x200B. §4.4.
