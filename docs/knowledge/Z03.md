# Z03 knowledge: zone combat, skills, abnormal states (facts for other items)

Pseudocode: [`docs/pseudocode/zone/Z03-combat.md`](../pseudocode/zone/Z03-combat.md). Names:
`tools/protocol-re/names/zone/Z03.json` (79). Layouts: `docs/protocol/annotations/Z03.json` (66 packets).

## 1. Answers to open questions

- **Z02 §15, flag byte `obj+0x1e78`:** bit 0 routine-ran, bit 1 alternate (ranged) damage path, **bit 2 Fear**, **bit 3 killed**
  (`so_KilledBy` ran), bit 4 skill blast armed, **bit 5 Captivate**, bit 6 ignore-cooldown, bit 7 generic switch (vt 0xbf0).
  Bit 5 is set by `smo_SetCaptivate` (FUN_0055d570, vt 0xf1c) from `SubAbnormalStateCaptivate` = `SubAbState.Type 70`
  (`SUBAB_CAPTIVATE`): abstates **StaKarenCaptivate (335)** and **StaWarLBrainWash (562)**, plus the GM command
  `&captivate`. A captivated player cannot move, target or cast and may be attacked by any player.
- **Player mode 5** = street booth (`so_KilledBy` calls `sp_CloseStreetBooth` when mode == 5).
- **`World/Field.txt` FieldList row** (packed, continues Z02 §3): MapIDClient 0x00, SubFrom 0x0d, SubTo 0x11, Serial 0x15,
  MapName 0x16, **KQ 0x36**, xsize 0x37, ysize 0x3b, **immortalsec 0x3f** (ms of StaImmortal after login/revive),
  ScriptName 0x41, ItemDropByKilled 0x61, Pker 0x62, **EnemyGuild 0x63**, Party 0x64, Monster 0x65, Summoned 0x66, IsPKKQ 0x67,
  IsFreePK 0x68, **IsPartyBattle 0x69**, NameHide 0x6a, LinkIN 0x6b, LinkOut 0x6c, SystemMap 0x6d, RegenCity 0x6e,
  RegenXA…YD 0x7a, RegenSpot 0x9a, CanRestart 0x9b, CanTrade 0x9c … CanParty 0xa6, **ExpLostAtDeadByMob 0xa7**,
  **ExpLostAtDeadByPly 0xa9** (‰). Field instance: `+0x54` free-PK flag, `+0x20c` bit 1 revival allowed, `+0x210` death-menu wait (s).

## 2. Shared mechanisms

- **Abnormal-state index** = `AbState.shn.AbStataIndex` (0…791; `0x318` = none). `g_AbState[idx]` (DAT_0087b060) →
  `{ → AbState row, → AbStateSaveTypeInfo row, resist slot, per-strength blocks at +0xc + strength*0x24 → SubAbState row }`.
  Check: `obj.vt[0x3e4](idx)` (HasAbstate, FUN_00555a20). Set: `vt[0x638](setter, idx, strength, entry, g_Now, 0, flag, keepMs, how, origin)`
  then `BriefAbstateBit_Set`, `so_AbnormalState_Inform` (0x2429/0x242A), `so_AbnormalState_BroadcastSet` (0x2427 + 0x1C18).
  Reset: `vt[0x650](idx)` (expires on the next tick → 0x2428). Element list at `obj+0xe7c` (0x74-byte elements, end time +0x20).
  Per-state behaviour = actor class by `SubAbState.Type` (`g_SubActors` DAT_008778ec, 27 virtual slots; table in Z03-combat §6.1).
- States tested by number all over the zone: 291 StaImmortal (login/revive protection), 499 StaAdlFLoussierIMT, 199 StaMobInvisible,
  392 StaCannotChangeTarget, 394 StaSoulFree, 326 StaEthereal, 365 StaMonkeyDefense, 345 StaRestExp, 201/202 StaACMode/StaMRMode.
- **Stat matrix** `obj.vt[0x430]()` (`player+0xfc0`): `param[layer*0xcc + stat*4]`, 51 stats, ≥ 16 layers.
  `Total(stat) = (L0+L1)·L12·L10·L4·L14/10¹² + L5+L7+L9+L11+L13`. Layers: 0 base, 1 item, 5/6 upgrade plus/rate, 8 weapon title,
  9/10 passive plus/rate, 11/12 abstate plus/rate, 15 total rate. Stats: 0 STR, 1 END, 2 DEX, 5/6 WC min/max, 7 AC, 8 TH, 9 TB,
  24 mastery, 26 shield block, 32/33 critical phys/magic. Special fields: +0xa18 attack-speed rate, +0xc30 flat damage,
  +0xcce flags (bit 2 cannot attack/cast), +0xcd0 forced hit rate, +0xcdc crit damage bonus. Z07 (parameter calculation) should
  confirm the layer names.
- **Rule sets** `obj+0x1e74`: `RulesOfEngagementNormalPY / NormalMA / PhisycalSkill / MagicalSkill` (vtable: +4 crit, +8 AP, +0xc DP,
  +0x10 damage, +0x18 hit rate, +0x1c `roe_CalcDamage`). Core: hit‰ = TH·850/TB; damage = AP·(level+1)/DP, then level-gap table
  (`DamageLvGapPVE/EVP/PVP.shn`), critical ×2, back-attack table (`World/DamageByAngle.txt`), abstate actor hooks.
- **Damage entry points:** `a.vt[0xef0](d, dmg, ctx)` → `d.so_DamagedBy` (vt 0x5c0) or `d.so_KilledBy` (vt 0x5bc).
  `ShineMobileObject::so_KilledBy` removes every abstate, sets mode 3, fires script interrupt 0x74 and clears the target of
  everyone targeting the victim. Death is signalled to clients only by the `dead` flag of the killing damage packet.
- **`hpchangeorder`** = `++(u16 obj+0x1d78)` via `vt[0x7e8]`: every HP-changing packet carries it; clients order HP updates by it.
- **Skill cast replies are deferred:** handlers store a code in `player+0x7f37`; `ShinePlayer::so_Routine` sends
  `0x2434 {u16 err}` on the next tick. `player+0x7f36` = "send 0x243D CEASE_FIRE" flag set by `smo_BashStop` (vt 0xed8).
- **SkillEntry** (`g_SkillData` DAT_13286828, `SkillDataBox_Find(id)`): `+0` ActiveSkillInfoServer row, `+4` ActiveSkill row
  (2017 PDB `ActiveSkillInfo` offsets hold for 2016), `+0x18/+0x1c` ToggleSkill rows, `+0x40` 4 abstates, `+0x70` rule set.
  Cast state `obj+0x1d84` (end time, skill id, target, xy, SkillEntry, produce recipe). Blast effects queue `g_BlastEffects`
  (DAT_0087efd4), results buffer `g_SkillResults` (64 × 0x18) → `0x2452`.
- **Player timers:** `player+0x2a784` one-shot `TimeScheduler` (`ts_Set(cb, arg, state, delayMs)`; states 2/3 swing, 4 gather);
  `player+0x173d0` delayed-hit queue (`NormalAttackDamageTick`).
- **Battle statistics** `obj.vt[0x428]()`: +4 kill exp, +8 damage, +0x14 criticals, +0x18 hits taken, +0x1c deaths×50,
  +0x20/+0x24 PvP deaths/kills, +0x28 PvP rating.
- **CharaterSkillList** `player+0x17d0c` (entry: +4 cooldown end, +8 SKILL_EMPOWER bits), passive list `player+0x17d30`;
  passive skill ids travel as `id + 30000` in erase packets.
- **Inventory locking pattern** (for Z04/Z06): item-consuming requests lock cells under `player+0xfaac` (lock index, incremented per
  request) in `player+0xfaa8`, send the DB request with the lock index, and release/commit on the DB answer.

## 3. Open questions for other items

- Z04: `NC_SKILL_EMPOW_RESET_REQ` (item → 0x480B), skill books → `0x4801`, revive items / soul stones → `sp_ReviveNow`;
  `UseItemNormal::uib_AfterCast` success → `so_ply_SkillEraseItemUseSuccess`.
- Z05: `NC_CHAR_REVIVE_REQ`, death menu timing (`player+0x2aa4c` auto-revive), `sp_2Roumen`.
- Z06: item actions (`vt[0x5d0]`, `ItemAction*.shn`) feeding hit/crit/shield rates; costume weapon/shield charges; mob drops
  (`dic_ItemDrop`) and looter choice (`el_FindLooter`).
- Z07: `so_allparametercalculate` and the stat-matrix layers; abstate save/restore (`AbstateShelter`, `NC_CHARSAVE_ABSTATE`);
  level-up side effects (stat points FUN_0058bd10, reward table DAT_14d42940).
- Z08: guild war request on illegal PvP attack (`sp_GuildWarRequest`), guild tournament kill hook FUN_0047e640, KQ contribution,
  PK count (`so_ply_SavePKCount`, 0x244A to WM).
- Z09: mob attacks and skills (`so_attack`, `so_Bash` packets 0x242C…0x2431), aggro (`vt[0x700]`), `so_Routine` tick order,
  abstate routine (`ListIter_ObjectAbStateRoutine`), magic fields, servants/pets.
- P-items: no combat capture exists; the layouts in `annotations/Z03.json` are code-read, not *(captured)*.
