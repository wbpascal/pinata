## Card roll

- `g_CardCollectMake(mobID, attr)` FUN_00628880, called only by `ItemAttrCls_CardCollect_Close::iac_DropItemMake`
  FUN_0063faf0 (item class 30, the sealed card `CC_Closed` ID 58272). Mob InxName → MobGroup → cards of the group
  (weights `CC_CardGetRate`, P = weight / group sum) → stars by card grade (`CC_StarRate`); both one-pass reservoir picks
  with `rb_1000000`. Returns false (drop cancelled) only for a mob without a MobGroup row with 2016 data.
- 2016 star odds: S 9★ 1/14, 8★ 5/14, 7★ 8/14; A 7/6/5★ same; B 5/4/3★ 1/3 each; C 3/2/1★ 1/3 each (§4.3).
- Sealed attr (9 bytes): SerialNumber u32 (0 at drop, numbered by the Character DB), CardID u16, Star u8, Group u16.
  Opened attr (class 31, 5 bytes): SerialNumber, Star. Opening copies them (§4.4, Z05 §6.6).
